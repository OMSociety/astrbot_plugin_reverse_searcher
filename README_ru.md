## ✨ Ключевые особенности

| Особенность | Описание |
|------|------|
| 🔍 **Пять поисковых движков** | AnimeTrace узнаёт персонажа, SauceNAO находит первоисточник, Google Lens служит универсальным запасным вариантом, Yandex ищет похожие изображения, а E-Hentai ищет додзинси — у каждого своя задача |
| 💬 **Триггер по ключевому слову** | Отправьте `以图搜图` (поиск по картинке) вместе с изображением — и поиск запустится; псевдонимы движков (`a`/`s`/`e`/`g`/`y`) позволяют быстро выбрать нужный движок |
| 🤖 **Поиск по инициативе LLM** | Бот сам решает, когда искать и каким движком пользоваться, исходя из смысла диалога — команды вводить не нужно |
| 🧭 **Маршрутизация по намерению** | Автоматически выбирает оптимальный движок на основе взвешенного сопоставления ключевых слов — скажите «кто это», и автоматически будет выбран AnimeTrace |
| 🎴 **Красивые карточки результатов** | Результаты поиска рендерятся в виде современных карточек-изображений (градиентная шапка в цветах движка, цветные значки схожести, метки ИИ-детекции); при недоступности облачного преобразования текста в изображение происходит автоматический откат на PIL |
| 🔄 **Свободное переключение движков** | Движки можно включать и отключать по мере надобности; при сбое происходит автоматическое переключение на резервный движок |

## 📖 Обзор возможностей

### Рендеринг карточек результатов
После завершения поиска автоматически создаётся карточка-изображение: исходное изображение и миниатюры результатов в одном кадре, схожесть видна с первого взгляда:

<img src="https://raw.githubusercontent.com/OMSociety/astrbot_plugin_reverse_searcher/main/docs/search_example.png" alt="搜索结果卡片示例" width="480" />

### Триггер по ключевому слову
Отправьте `以图搜图` вместе с изображением (или в ответ на цитируемое сообщение) и следуйте подсказкам:

```
用户: 以图搜图
🤖 → 发送引擎介绍卡片，请选择引擎
用户: a 这张图
🤖 → 已选择 AnimeTrace，正在搜索...
     → 发送搜索结果卡片 ✅
```

### Поиск по инициативе LLM
В бота встроен инструмент `reverse_search`; он сам решает по содержанию диалога, нужно ли выполнять поиск:

```
用户: 芙兰，帮我看看这张图的角色是谁
🤖 → reverse_search(intent=找角色)
    🔍 [AnimeTrace] 找到 3 个结果
    角色: 芙兰朵露·斯卡蕾特 | 作品: 东方Project...
```

### Маршрутизация по намерению
Движок указывать не нужно — достаточно назвать намерение, и он выберется автоматически:

| Намерение | Автоматический выбор |
|------|---------|
| «Кто это / какой персонаж / косплеи» | → AnimeTrace |
| «Найти источник / найти автора / pixiv pid» | → SauceNAO |
| «Найти похожие / похоже на это» | → Yandex |
| «Найти додзинси / фан-работы» | → E-Hentai |
| «Найти оригинал / общий поиск» | → Google |

## 🚀 Быстрый старт

### Шаг 1: установка

**Способ 1: маркетплейс плагинов**
- AstrBot WebUI → Маркетплейс плагинов → найдите `astrbot_plugin_reverse_searcher`

**Способ 2: репозиторий GitHub**
- AstrBot WebUI → Управление плагинами → ＋ Установить → вставьте адрес репозитория:
- `https://github.com/OMSociety/astrbot_plugin_reverse_searcher`

### Шаг 2: минимальная настройка (работает сразу после установки)

**Настройка не требуется** для трёх движков без ключей — AnimeTrace, Yandex и E-Hentai:

1. После перезапуска AstrBot просто отправьте `以图搜图` + изображение
2. Или просто попросите бота «посмотри, кто этот персонаж», и LLM выполнит поиск автоматически

> 💡 Необязательные расширения: настройте `api_key` для SauceNAO ([страница заявки](https://saucenao.com/user.php)), чтобы открыть поиск по художникам/источникам; движку Google нужен [ключ SerpAPI](https://serpapi.com/); для ExHentai требуется действительный Cookie.

### Установка зависимостей
Плагин зависит от `httpx`, `Pillow`, `pyquery` и др.; AstrBot устанавливает их автоматически при установке плагина.

## 🔍 Поддерживаемые поисковые движки

| Движок | Описание | Настройка |
|:----|:----|:----|
| **animetrace** | Распознавание аниме-персонажей (самое сильное); возвращает название произведения + имя персонажа | ❌ Настраивать не нужно |
| **yandex** | Поиск похожих изображений | ⚠️ Рекомендуется задать Cookie (у Yandex строгая защита от ботов; без Cookie возможны CAPTCHA или пустой результат) |
| **ehentai** | Поиск додзинси на E-Hentai | ❌ Настраивать не нужно (для ExHentai нужен Cookie) |
| **saucenao** | Универсальный поиск источника; первый выбор для иллюстраций Pixiv | ⚠️ Рекомендуется задать `api_key` |
| **google** | Универсальный запасной вариант Google Lens | ✅ Нужен ключ SerpAPI |

## ⚙️ Описание параметров конфигурации

### Параметры верхнего уровня

| Параметр | Тип | По умолчанию | Описание |
|--------|------|------|------|
| `enable_keyword_trigger` | bool | `true` | Переключатель триггера по ключевому слову; после отключения доступны только инструменты LLM |
| `proxies` | string | `""` | Адрес прокси, например `http://127.0.0.1:7890` (обязателен при доступе из материкового Китая) |
| `allow_third_party_image_host` | bool | `true` | Разрешить ли загрузку локальных изображений на сторонние временные image-хостинги (нужно для поиска по локальным изображениям в Google/Yandex; при отключении эти два движка не смогут искать по локальным изображениям) |

### Настройки таймаутов `timeout_settings`

| Параметр | Тип | По умолчанию | Описание |
|--------|------|------|------|
| `search_params_timeout` | int | `30` | Таймаут (в секундах) ожидания от пользователя движка/изображения |

### Ключевые слова `keyword`

| Параметр | Тип | По умолчанию | Описание |
|--------|------|------|------|
| `trigger_keywords` | list | `["以图搜图"]` | Список ключевых слов, запускающих поиск |
| `engine_keywords` | object | `a/s/e/g/y` | Пользовательские псевдонимы движков (animetrace=`a`, saucenao=`s`, ehentai=`e`, google=`g`, yandex=`y`) |

### Включённые движки `available_apis`

| Параметр | Тип | По умолчанию | Описание |
|--------|------|------|------|
| `animetrace` / `ehentai` / `google` / `yandex` / `saucenao` | bool | `true` | Переключатели включения/отключения каждого движка |

### Параметры движков по умолчанию `default_params`

| Параметр | Описание |
|--------|------|
| `animetrace.model` | Модель распознавания, по умолчанию `full_game_model_kira` |
| `animetrace.is_multi` / `ai_detect` | Поиск нескольких персонажей / детекция ИИ |
| `ehentai.is_ex` / `covers` / `similar` / `exp` | Переключатель ExHentai; режимы обложек/похожего/экспериментальный |
| `ehentai.cookies` | **Cookie для E-Hentai** (обязателен для ExHentai; как получить — см. FAQ, вопрос Q5) |
| `google.serpapi_key` / `zenserp_key` | Ключи SerpAPI (рекомендуется) / Zenserp (резервный) |
| `google.hl` / `country` / `max_results` | Язык / регион / максимальное число результатов |
| `saucenao.api_key` / `minsim` / `numres` | Ключ API / минимальная схожесть / число результатов |
| `yandex.max_results` / `use_ru_fallback` | Число результатов / переключение на домен `.ru` |
| `yandex.cookies` | **Cookie для Yandex** (строгая защита от ботов; без Cookie возможны CAPTCHA и пустой результат; как получить — см. Q5) |

> 🔐 **Раскрытие информации о приватности: локальные изображения загружаются на сторонние image-хостинги** — при поиске в **Google / Yandex** по **локальному изображению** плагину нужно сначала загрузить изображение на временный image-хостинг (`tmpfiles.org` / `uguu.se` / `litterbox.catbox.moe` / `tmp.ninja`) и только затем выполнять поиск по URL. **Это означает, что ваше изображение будет загружено на общедоступный временный image-хостинг**, а срок его хранения определяется третьей стороной. Чтобы отключить это, установите `allow_third_party_image_host` в `false` (в этом случае эти два движка не смогут искать по локальным изображениям; используйте URL изображения или другой движок).

### Быстрый шаблон конфигурации

```json
{
  "enable_keyword_trigger": true,
  "proxies": "",
  "allow_third_party_image_host": true,
  "timeout_settings": {
    "search_params_timeout": 30
  },
  "keyword": {
    "trigger_keywords": ["以图搜图"],
    "engine_keywords": { "animetrace": "a", "ehentai": "e", "google": "g", "yandex": "y", "saucenao": "s" }
  },
  "available_apis": { "animetrace": true, "ehentai": true, "google": true, "yandex": true, "saucenao": true },
  "default_params": {
    "animetrace": { "model": "full_game_model_kira", "is_multi": false, "ai_detect": false },
    "ehentai": { "is_ex": false, "covers": false, "similar": true, "exp": false, "cookies": "" },
    "google": { "serpapi_key": "", "zenserp_key": "", "hl": "zh-CN", "country": "HK", "max_results": 10 },
    "saucenao": { "api_key": "", "hide": 3, "numres": 5, "minsim": 30, "output_type": 2 },
    "yandex": { "max_results": 10, "use_ru_fallback": true, "cookies": "" }
  }
}
```

## 🛠️ Инструменты, доступные для LLM

Плагин регистрирует 2 инструмента LLM; бот сам решает, когда их вызывать:

```
用户: 这张图是什么角色？
🤖 → reverse_search(intent=找角色)
    🔍 [AnimeTrace] 找到 3 个结果
    角色: 芙兰朵露·斯卡蕾特 | 作品: 东方Project...

用户: 用 SauceNAO 查一下这张图的画师
🤖 → reverse_search_with_engine(engine=saucenao)
    🔍 [SauceNAO] 找到 5 个结果
    Pixiv: 画师 KuroNeko | 相似度 95.2%
```

### reverse_search
Универсальный инструмент поиска изображений; автоматически выбирает движок по намерению.

| Параметр | Тип | Описание |
|------|------|------|
| `image_base64` | string? | Изображение в кодировке base64 (или URL — что-то одно) |
| `image_url` | string? | URL изображения (или base64 — что-то одно) |
| `intent` | string? | Намерение поиска (например «найти персонажа», «найти источник», «найти похожие»), используется для автоматического выбора движка |

### reverse_search_with_engine
Поиск с указанием движка; вызывается, когда пользователь явно просит определённый движок.

| Параметр | Тип | Описание |
|------|------|------|
| `image_base64` / `image_url` | string? | Источник изображения (что-то одно) |
| `engine` | string | **Обязательно**, имя движка: `animetrace` / `saucenao` / `ehentai` / `google` / `yandex` |

## 🔧 Частые вопросы

### Q1: Каким движкам нужен API-ключ?

| Движок | Настройка |
|------|---------|
| AnimeTrace / Yandex / E-Hentai | Не нужен — работает сразу после установки |
| SauceNAO | Рекомендуется задать `api_key` ([бесплатная заявка](https://saucenao.com/user.php), 150 запросов в день) |
| Google | Нужен [ключ SerpAPI](https://serpapi.com/) (рекомендуется) или ключ Zenserp |

### Q2: E-Hentai не ищет / хотите видеть содержимое ExHentai?

- E-Hentai ищет без настройки; для **ExHentai** нужен Cookie аккаунта (`ipb_member_id`, `ipb_pass_hash`, `igneous`), который вставляется в `default_params.ehentai.cookies`, и включённый параметр `is_ex`

### Q3: На сервере в материковом Китае поиск медленный / ничего не находит?

Укажите прокси в `proxies` (например `http://127.0.0.1:7890`). SauceNAO, Google, Yandex и другие движки применяют риск-контроль к китайским IP, поэтому прокси обязателен.

### Q4: Карточка с результатами не создаётся?

Плагин в первую очередь использует облачное преобразование текста в изображение (t2i) AstrBot для рендеринга HTML-карточек; если облако недоступно или отвечает таймаутом, происходит **автоматический откат на встроенный рендеринг PIL** (изображение всё равно создаётся). Чистый текст используется только если не сработали оба способа. Обновление AstrBot до последней версии повышает стабильность облачного рендеринга.

### Q5: Как получить Cookie для Yandex / E-Hentai и что вставлять в настройки плагина?

Cookie — это учётные данные, которые браузер автоматически сохраняет после входа на сайт. Вставлять нужно **целую строку формата `name1=value1; name2=value2`**. Два способа получить её (выберите любой):

**Способ 1: одна команда в консоли (самый простой, попробуйте сначала)**
1. Откройте нужный сайт в браузере и **войдите в аккаунт** (E-Hentai: https://e-hentai.org; ExHentai: https://exhentai.org; Yandex: https://yandex.com/images)
2. Нажмите **F12** → откройте вкладку **Console (консоль)** вверху
3. Введите в строке ввода внизу `document.cookie` и нажмите **Enter**
4. Консоль сразу выведет целую строку Cookie → **скопируйте её** (вида `ipb_member_id=123; ipb_pass_hash=abc; ...`)
5. ⚠️ Ограничение: поля с флагом **HttpOnly** так получить нельзя — **для E-Hentai этого достаточно**; **у Yandex часть ключевых полей — HttpOnly, лучше используйте способ 2**

**Способ 2: панель Network (полный, рекомендуется для Yandex)**
1. Войдя на нужный сайт, нажмите **F12** → откройте вкладку **Network (сеть)**
2. ⚠️ **Внимание: в поле фильтра сверху не вводите ничего** (введённый текст отфильтрует запросы, и список окажется пустым!), оставьте его пустым
3. **Обновите страницу** (F5) → слева появится список запросов → **щёлкните первый запрос**
4. Справа откройте **Headers (заголовки)** → прокрутите до блока **Request Headers (заголовки запроса)**
5. Найдите строку, начинающуюся с **`Cookie:`** → **скопируйте её целиком** (всё содержимое после `Cookie:`)

Скопированный текст выглядит примерно так (точные значения зависят от аккаунта):
```
yandexuid=1587138991653; ymex=1986384493.yrts.159; Session_id=3:163...:0
```
Вставьте всю строку в параметр конфигурации плагина `default_params.yandex.cookies` / `default_params.ehentai.cookies`.

> 💡 У Yandex строгая защита от ботов: без Cookie может появиться CAPTCHA, и поиск не даст результатов; для поиска содержимого ExHentai через E-Hentai Cookie обязателен (с тремя ключевыми полями `ipb_member_id`, `ipb_pass_hash` и `igneous`). Надёжнее всего получать Cookie с того домена, к которому плагин реально обращается (yandex.com).
